# Toxic Tales — research library and free production tools

Dedicated project for Instagram **@toxic_tales_eco**.

This is a new, independent repository. It does not reuse or modify any other project or website.

## Scope and cost

- The only authorised repository is `akshaymohan16/toxic-tales-library`.
- Do not read, write, deploy, or copy from unrelated repositories.
- No paid APIs, purchases, subscriptions, paid runners, or paid hosting.
- Keep credentials, personal data, and publisher PDFs out of this public repository.

## Pipeline

Source-checked episode JSON → offline video / carousel rendering → public source library → connected Metricool scheduling.

Target after successful deployment: **two Reels and one carousel per week**, using the Europe/Vienna timezone. The GitHub workflow builds media and the library; the separate ChatGPT automation performs research and uses the connected Metricool tools. This repository alone does not autonomously research or post to Instagram.

GitHub Pages must be enabled with **Settings → Pages → Source: GitHub Actions**. A successful build is not the same as a successful public deployment. Publishing must stop if the library, source links, or media are unavailable.
